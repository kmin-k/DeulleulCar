**해석**: 볼일을 들르려면 지금은 출발 전에 경유지를 하나하나 검색해서 넣거나, 주행 중에 조작해야 한다(불법이자 위험). 핸즈프리 통화조차 인지 부하가 있으니, 핵심은 "한 마디로 끝나고 확인 1번"인 음성 UX다.

## 4. 경쟁·대체재 비교 (기획서 3번 차별점)
| 대안 | 할 수 있는 것 | 못 하는 것 |
|---|---|---|
| 폰 내비 (티맵·카카오내비 등) | 목적지·경유지 수동 추가 | 차량 상태를 모름. 자연어 다중 볼일 + 영업시간 반영 순서 최적화 없음 (**공식 기능 목록 재확인 필요**) |
| 차량 계기판 경고등 | 이상 감지·표시 | 의미 설명, 긴급도 판단, 해결 장소·시간 제안, 일정과 묶기 |
| 제조사 커넥티드 앱 (원격 진단 알림 등) | 폰으로 진단 알림 (**기능 범위 확인 필요**) | 주행 중 경로에 해결 기회를 자연스럽게 합치는 것 |
| Google Routes API 등 | 경유지 순서 최적화(개발자용) | 차량 데이터, 한국어 볼일 대화, 국내 POI |

**들를Car의 자리**: "차량 데이터 × 내 일정 × 경로"의 교집합. 폰은 차 상태를 모르고, 차는 내 사정을 모른다.

## 5. MAU·리텐션 산정 틀 (T18에서 확정)
- 설치 기반: Pleos Connect 탑재 차량 = 2026 그랜저부터 순차 확대, 2030년 약 2,000만 대(글로벌)
- 산식(가정은 명시): 국내 탑재 차량 × 앱 마켓 활성 비율 × 설치율 × 월간 사용률
  - 가정값은 보수/기준/낙관 3개 시나리오로 제시하고, 근거가 없는 숫자는 "가정"이라고 표시
- 리텐션 근거: 차의 할 일은 차가 계속 만들어 냄(계절성 공기압, 연료, 워셔액, 정기 점검) → 사용자가 앱을 잊어도 다시 돌아올 계기가 생김. 볼일 경유는 주 단위로 반복되는 생활 행동

## 6. 1차 조사 제안 (👤 선택, 가산 효과 큼)
2차 자료에는 "경유 볼일 빈도", "경고등을 보고 미룬 경험" 같은 수치가 없다. 직접 짧은 설문을 돌리면 기획서 2번(배경)의 설득력이 크게 올라간다.
- 대상: 운전하는 지인·대학 커뮤니티 30명 이상 (익명, 개인정보 미수집)
- 문항 초안
  1. 운전할 때 목적지 외에 1곳 이상 들르는 날은 일주일에 며칠인가요? (0 / 1~2 / 3~4 / 5+)
  2. 들를 곳을 내비에 넣는 시점은? (출발 전에 전부 / 가다가 조작 / 그냥 기억해서 감)
  3. 갔는데 영업이 끝나서 헛걸음한 적이 최근 3개월 안에 있나요?
  4. 계기판 경고등이 켜진 뒤 해결까지 걸린 기간은? (당일 / 1주 내 / 1달 내 / 그 이상 / 아직)
  5. 경고등이 켜졌을 때 가장 먼저 한 일은? (검색 / 무시 / 정비소 전화 / 기타)
  6. "가는 길에 3분만 들르면 해결돼요"라는 제안이 오면 받아들이시겠어요? (5점 척도)
- 산출: 응답 수와 기간을 명시하고 기획서 2번·6번에 인용
